# 👑 CHRDK REBORN — База знаний VKChat Ultimate

Добро пожаловать в вики **VKChat Ultimate** — RPG-экосистемы Minecraft ↔ ВКонтакте для сервера **CHRDK REBORN**.

## Быстрый старт игрока

1. Зарегистрируйся:

```text
/register <пароль>
```

2. Привяжи ВК:

```text
/vklink
```

3. Открой главное меню:

```text
/menu
```

4. Выбери нацию:

```text
/nation
```

5. Начни профессии:

```text
/jobs
```

6. Когда выйдешь с сервера — напиши VK-боту в ЛС:

```text
!поход
```

## Что нового в 2.0.0

- Кузня 2.0: хаб `/forge`, слияние редкости, свитки, защита, логи.
- Offline 2.0: кампания, психика, травмы, госпиталь, коллекции, магазин, навыки.
- Jobs 2.0: ежедневки и специализации.
- Market 2.0: тренды дня, история, ротация редкостей.
- Mobs/Events 2.0: контракты, рейд-боссы, мировые угрозы.
- DonatePay: 4 месячных статуса с LuckPerms-группами.
- Короткие названия наций: Совет, КГБ, Волхвы, Культ, Русь, Опричнина.
