# Полный список команд

## Игрок

### Авторизация
| Команда | Описание |
|---|---|
| `/register <пароль>` | Регистрация |
| `/login <пароль>` | Вход |
| `/2fa <код>` | Двухфакторка |
| `/vklink` | Привязка ВК |
| `/vkunlink` | Отвязать ВК |
| `/changepass <старый> <новый>` | Смена пароля |
| `/logout` | Выход |

### Экономика
| Команда | Описание |
|---|---|
| `/rep` | Репутация |
| `/bal` | Баланс репутации |
| `/pay <игрок> <сумма>` | Перевод (подтверждение >100) |
| `/online` | Онлайн сервера |
| `/lastseen <ник>` | Последнее появление |

### Нации
| Команда | Описание |
|---|---|
| `/nation` | Меню нации |
| `/nation info` | Инфо о нации |
| `/nation top` | Топ наций |
| `/nation buyclaim` | Купить приват |
| `/nation claims` | Ваши приваты |
| `/nation trust <игрок>` | Добавить в приват |
| `/nation untrust <игрок>` | Убрать из привата |
| `/nation sethome` | Точка дома |
| `/nation home` | Телепорт домой (20 реп.) |
| `/nation tp <X> <Y> <Z>` | Телепорт к привату (20 реп.) |
| `/nation defend` | Запуск обороны привата |
| `/nation leave` | Покинуть нацию |
| `/nation festival` | Фестиваль (1000 реп.) |
| `/nation change` | Смена нации (5000 реп.) |

### Профессии
| Команда | Описание |
|---|---|
| `/jobs` | Меню профессий |
| `/jobs daily` | Ежедневные задания |
| `/jobs claim <проф>` | Забрать ежедневную награду |
| `/jobs spec <проф> <тип>` | Выбрать специализацию |
| `/jobs weekly` | Еженедельные задания |
| `/jobs weekly claim <тип>` | Забрать еженедельную награду |
| `/jobs rank` | Рейтинг профессий |
| `/jobs top` | Топ игроков |
| `/jobs info` | Справка |

### Телепорт

## Админ

| Команда | Право | Описание |
|---|---|---|
| `/vkchat give <ник> <кол-во>` | `vkchat.admin` | Начислить репутацию |
| `/vkchat set <ник> <кол-во>` | `vkchat.admin` | Установить репутацию |
| `/vkchat unlink <ник>` | `vkchat.admin` | Отвязать ВК |
| `/vkchat linked` | `vkchat.admin` | Привязанные аккаунты |
| `/vkchat promo <код> <uses> <reward>` | `vkchat.admin` | Промокод |
| `/vkchat wall <текст>` | `vkchat.admin` | Пост в ВК |
| `/mute <ник> <минуты>` | `vkchat.moderator` | Замутить |
| `/unmute <ник>` | `vkchat.moderator` | Размутить |
| `/donatepay give <ник> <статус>` | `vkchat.admin` | Выдать статус |
| `/donatepay reload` | `vkchat.admin` | Перезагрузить |
| `/nation admin unclaim <ник>` | `vkchat.admin` | Снять приваты |
