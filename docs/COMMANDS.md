# 📜 Полный список команд VKChat Ultimate

## Для игроков

### Авторизация и безопасность
| Команда                    | Описание                                      | Пример                  |
|---------------------------|-----------------------------------------------|-------------------------|
| `/register <пароль>`      | Регистрация аккаунта                          | `/register MyPass123`   |
| `/login <пароль>`         | Вход в аккаунт                                | `/login MyPass123`      |
| `/2fa <код>`              | Ввод кода двухфакторной аутентификации        | `/2fa 4821`             |
| `/vklink`                 | Получить код привязки ВК                      | `/vklink`               |
| `/vkunlink`               | Отвязать ВК                                   | `/vkunlink`             |
| `/changepass <старый> <новый>` | Смена пароля                             | `/changepass old new`   |
| `/logout`                 | Выход из аккаунта                             | `/logout`               |

### Репутация и экономика
| Команда                    | Описание                                      | Пример                     |
|---------------------------|-----------------------------------------------|----------------------------|
| `/rep`                    | Посмотреть свою репутацию                     | `/rep`                     |
| `/pay <игрок> <кол-во>`   | Перевести репутацию другому игроку            | `/pay Steve 150`           |

### Нации и приваты
| Команда                           | Описание                                           |
|-----------------------------------|----------------------------------------------------|
| `/nation`                         | Главное меню нации                                 |
| `/nation buyclaim`                | Купить блок привата                                |
| `/nation claims`                  | Список ваших приватов                              |
| `/nation trust <игрок>`           | Добавить друга в приват                            |
| `/nation untrust <игрок>`         | Убрать из доверенных                               |
| `/nation sethome`                 | Установить точку дома в привате                    |
| `/nation home`                    | Телепорт на точку дома (20 реп.)                   |
| `/nation tp <X> <Y> <Z>`         | Телепорт к блоку привата (20 реп.)                 |
| `/nation defend`                  | Запустить защиту привата (Рейд/Осада/Диверсия)     |
| `/nation festival`                | Фестиваль нации (1000 реп. из казны)               |
| `/nation change`                  | Смена нации (5000 реп.)                            |

### Телепортация
| Команда                    | Описание                              |
|---------------------------|---------------------------------------|
| `/rtp`                    | Случайный телепорт в wild             |
| `/sethome [имя]`          | Установить точку дома                 |
| `/home [имя]`             | Телепорт домой                        |
| `/tpa <игрок>`            | Запрос телепорта к игроку             |
| `/tpaccept`               | Принять запрос                        |
| `/tpdeny`                 | Отклонить запрос                      |

### Gear и Кузня
| Команда                    | Описание                              |
|---------------------------|---------------------------------------|
| `/forge`                  | Открыть кузню                         |
| `/runes`                  | Магазин рун                           |
| `/artifacts`              | Магазин артефактов                    |

### Другое
| Команда                    | Описание                              |
|---------------------------|---------------------------------------|
| `/menu`                   | Главное меню сервера                  |
| `/market`                 | Открыть рынок                         |
| `/jobs`                   | Профессии                             |
| `/donatepay status`       | Статус DonatePay                      |

## Для администраторов

### Основные админ-команды
| Команда                              | Описание                                      | Право              |
|--------------------------------------|-----------------------------------------------|--------------------|
| `/vkchat give <игрок> <кол-во>`      | Начислить репутацию                           | `vkchat.admin`     |
| `/vkchat set <игрок> <кол-во>`       | Установить репутацию                          | `vkchat.admin`     |
| `/vkchat unlink <игрок>`             | Принудительно отвязать ВК                     | `vkchat.admin`     |
| `/vkchat linked`                     | Список привязанных аккаунтов                  | `vkchat.admin`     |
| `/vkchat promo <код> <uses> <reward>`| Создать промокод                              | `vkchat.admin`     |
| `/vkchat wall <текст>`               | Опубликовать анонс в ВК                       | `vkchat.admin`     |
| `/vkchat migrate`                    | Миграция данных из YML в SQL                  | `vkchat.admin`     |

### Модерация
| Команда                    | Описание                              | Право                  |
|---------------------------|---------------------------------------|------------------------|
| `/mute <игрок> <минуты>`  | Замутить игрока                       | `vkchat.moderator`     |
| `/unmute <игрок>`         | Размутить игрока                      | `vkchat.moderator`     |

### Управление нациями
| Команда                              | Описание                              |
|--------------------------------------|---------------------------------------|
| `/nation admin unclaim <игрок>`      | Снять все приваты игрока              |
| `/nation admin force <игрок>`        | Принудительные действия               |

### DonatePay
| Команда                              | Описание                              |
|--------------------------------------|---------------------------------------|
| `/donatepay give <игрок> <статус>`   | Выдать статус                         |
| `/donatepay reload`                  | Перезагрузить DonatePay               |

---

**Примечание:** Все команды требуют соответствующих прав. Подробнее — в [PERMISSIONS.md](PERMISSIONS.md).
