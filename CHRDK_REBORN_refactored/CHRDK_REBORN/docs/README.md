# CHRDK REBORN

RPG-экосистема **Minecraft ↔ ВКонтакте** на сервере Purpur 1.20.4.

---

## Быстрый старт

```
/register <пароль>
/vklink
/menu
/nation
/jobs
```

---

## Модули (12)

| Модуль | Назначение |

| **VKChat Core** | Ядро: авторизация, VK-интеграция, команды |

## Игровые системы

### Нации (6)
Совет, КГБ, Волхвы, Культ, Русь, Опричнина — каждая со своим бонусом.

### Приваты (5 уровней)
Защита территории: Basic → Advanced → Elite → Ultimate → Legendary.

### Gear и Руны
- 22 набора снаряжения
- 5 Mythical наборов
- 4 тира кристаллов (Common → Ancient)
- Максимальная заточка **+25**
- 5 новых зачарований

### Профессии (7)
Шахтер, Лесоруб, Фермер, Алхимик, Кузнец, Охотник, Рыбак.
- Навыки (9 на профессию + продвинутые lvl 45)
- Ежедневные задания
- Еженедельные задания
- Рейтинг с наградами
- Специализации (XP / Stamina / Reward)

### События
- 16 катаклизмов (автоспавн каждые 5 мин)
- MobStorm — мировое событие
- Контракты элементалов
- Рейд-боссы

### Артефакты
Легендарные предметы с проклятиями, Mythic шанс (0.1%).

### Рынок
Динамические цены, тренды, история, лимитированные товары.
