# Артефакты (VKChat Artifacts)

Артефакты — легендарные предметы с проклятиями, падающие с мобов.

## Механика

- Каждый артефакт имеет **проклятие** (негативный эффект при ношении)
- Проклятие усиливается на **1% каждые 60 минут** ношения
- При достижении **100%** — артефакт разрушается навсегда
- **Mythic шанс**: 0.1% — выпадает артефакт БЕЗ проклятий

## Рарности

| Рарность | Шанс падения | Цвет |
