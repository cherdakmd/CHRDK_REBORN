# События (VKChat Events)

## Катаклизмы (16)

Автоматически спавнятся каждые 5 минут с 8% шансом рядом с игроками (радиус 64 блока).

**Все катаклизмы НЕ затрагивают приваты наций.**

| Катаклизм | Описание | Урон/эффекты |
|---|---|---|
| **Invasion** | Вторжение мобов | 3 волны по 5 мобов |
| **Eclipse** | Затмение | 30 сек тьмы, слабость I |
| **Fog Shadows** | Тени тумана | Сгустки, 4 урона, nausea |
| **Plasma Storm** | Плазменная буря | Лайтнинги, 6 урона |
| **Gravity Anomaly** | Гравитационная аномалия | Подбрасывание, 5 урона |
| **Corrupted Lands** | Заражённая земля | Скелеты+зомби, ядовитые лужи |
| **Ice Age** | Ледниковый период | Снег, замедление, 4 урона |
| **Volcanic Eruption** | Извержение вулкана | Лава, огненные шары, 8 урона |
| **Soul Storm** | Буря душ | 15 сгустков, 4 урона, Wither |
| **Toxic Cloud** | Токсичное облако | 8 облаков, Poison II, урон/тик |
| **Crystal Rain** | Кристальный дождь | 20 кристаллов, 6 урона, взрывы |
| **Shadow Realm** | Теневое измерение | Теневые мобы, darkness |
| **Blood Moon** | Кровавая луна | Усиленные мобы, +50% HP |
| **Magnetic Storm** | Магнитная буря | Случайные телепорты |
| **Void Rift** | Разлом Бездны | Эндермены, эндер-шары |
| **Corrupted Beast** | Заражённый зверь | Босс с уникальными способностями |

## Автоспавн

Каждые 300 секунд, 8% шанс, радиус 64 блока от случайного игрока. Катаклизм не затрагивает:
- Приваты наций
- Территорию нации (если игрок внутри)

## Ивенты

| Ивент | Описание | Награда |
|---|---|---|
| **Treasure Hunt** | 5 подсказок, сокровища | 200 реп. + редкие предметы |
| **Escort Mission** | Защитить NPC, 3 волны | 300 реп. + тотем/элитра |
