# Рынок (VKChat Market)

Динамический рынок с трендами, историей цен и лимитированными товарами.

## Команда

```
/market
```

## Механики

### Тренды
Цены меняются в пределах **0.75x — 1.35x** от базовой каждые сутки.

### Ротация
Каждые сутки 2 случайных предмета становятся **лимитированными** с увеличенной ценой.

### Скидки DonatePay
| Статус | Скидка покупки |
|---|---|
| Искра | -10% |
| Пламя | -30% |
| Звезда | -60% |
| Легенда | -100% (бесплатно) |

### История
Рынок хранит историю цен и объёмов. Минимальный объём для логирования: 64 единицы.
